# ระบบบริหารจัดการเงินออมทรัพย์เพื่อการผลิต

เว็บแอปสำหรับจัดการสมาชิก เงินฝาก ถอนเงิน ดอกเบี้ย และรายงาน โดยใช้ Next.js + TypeScript + Tailwind CSS และ Neon PostgreSQL

## Database
Neon PostgreSQL — project: `savings-production-management`

## เริ่มต้นพัฒนา
```bash
npm install
npm run dev
```

ตั้งค่า `.env.local`:
```env
DATABASE_URL=your_neon_connection_string
```
